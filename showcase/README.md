# Tao UI Showcase

Демонстрационное приложение для библиотеки компонентов Tao UI.

## Запуск

1. Убедитесь, что основная библиотека собрана:
```bash
cd ..
npm run build
```

2. Установите зависимости showcase:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Откройте браузер по адресу, указанному в терминале (обычно http://localhost:5173)

## Структура

- `App.vue` — главная страница со всеми компонентами
- `main.js` — точка входа приложения
- `index.html` — HTML-шаблон
- `vite.config.js` — конфигурация Vite
- `package.json` — зависимости и скрипты

## Использование

В App.vue представлены все компоненты библиотеки с примерами использования и готовыми сниппетами кода для копирования.

Каждый компонент демонстрируется в отдельной секции с:
- Названием и описанием
- Визуальными примерами
- Различными вариантами использования
- Готовым кодом для копирования
